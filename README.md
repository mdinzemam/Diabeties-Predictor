# 🩺 Diabetes Prediction System

An end-to-end Machine Learning web application deployed using Streamlit to predict the onset of diabetes based on diagnostic biometric measures.

## 📌 Project Overview
This project leverages machine learning to assist in the early risk assessment of diabetes using clinical metrics. The model is trained on the Pima Indians Diabetes dataset and packaged into an interactive user interface where users can input patient health indicators to receive instant predictions.

### Key Biometric Features:
- **Pregnancies:** Number of times pregnant
- **Glucose:** Plasma glucose concentration (2 hours in an oral glucose tolerance test)
- **Blood Pressure:** Diastolic blood pressure ($mm\ Hg$)
- **Skin Thickness:** Triceps skin fold thickness ($mm$)
- **Insulin:** 2-Hour serum insulin ($mu\ U/ml$)
- **BMI:** Body mass index ($\text{weight in kg} / (\text{height in m})^2$)
- **Diabetes Pedigree Function:** Genetic score indicating family history of diabetes
- **Age:** Age in years
